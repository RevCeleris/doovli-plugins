# Doovli plugins for Claude

Free Claude plugins from Doovli, a RevCeleris company.

| Plugin | What it does |
| --- | --- |
| Topics Hub with Timeback Machine™ | Organizes your Claude chats and everything you've made under the subjects you keep coming back to, keeps a self-updating hub page for each one, and checks your work daily for time it can give back. |
| Prior Inventions Tracker | Finds what you built on your own in Claude, dates each item from a record you can check, and builds the prior inventions list an employment or contractor agreement asks for. |
| Career Opportunity Tracker | Finds jobs and consulting or fractional clients twice a week, drafts tailored resumes, cover letters and outreach, and keeps your weekly work search log ready. |

## Add them to Claude

In Claude on the web or desktop: open Customize, then Plugins, then Add, then Add marketplace, and enter `RevCeleris/doovli-plugins`. Add the plugins you want, then start a new chat and ask, for example, "Set up my Topics Hub."

In Claude Code:

    /plugin install topics-hub --marketplace RevCeleris/doovli-plugins
    /plugin install prior-inventions-tracker --marketplace RevCeleris/doovli-plugins
    /plugin install career-opportunity-tracker --marketplace RevCeleris/doovli-plugins
