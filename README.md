# Doovli plugins for Claude

Free Claude plugins from Doovli, created by Rich Henderson.

| Plugin | What it does |
| --- | --- |
| Topics Hub with Hour Finder™ | Organizes your Claude chats and everything you've made under the subjects you keep coming back to, keeps a self-updating hub page for each one, and checks your work daily for time it can give back. |

Prior Inventions and the Career Opportunity Tracker are coming next.

## Add them to Claude

In Claude on the web or desktop: open Customize, then Plugins, then Add, then Add marketplace, and enter `RevCeleris/doovli-plugins`. Add the plugins you want, then start a new chat and ask, for example, "Set up my Topics Hub."

In Claude Code:

    /plugin install topics-hub --marketplace RevCeleris/doovli-plugins
