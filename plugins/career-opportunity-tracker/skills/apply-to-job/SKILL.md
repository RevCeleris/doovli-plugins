# Apply to a job (version 4.4)

My request: "Add this job to my Career Opportunity Tracker. Then tailor my resume and cover letter to it and save both files."

This skill works through my tracker page in Claude in Chrome. If Claude in Chrome is not available here, tell me in one sentence and stop.

## Before you start

- Find my tracker: list my artifacts and use the page titled "Career Opportunity Tracker". If there is more than one, ask me once which to use.
- Where finished files go: my Downloads folder, unless I have said otherwise in this chat or in my saved preferences, for example a folder named for the company inside a Google Drive folder I named.
- Things I have not done and must never be claimed: anything I have told you in this chat or in my saved preferences, for example no college degree or never managed a team.

## Steps

### 1. Read the posting
Read the job from the Chrome tab I have open. If I gave a link instead, open it. Capture the company, job title, location, pay exactly as written, the listing link, and the full job description.
- Many careers pages load the listing inside an embedded frame, so the page text can come back nearly empty. If that happens, find the job board the page embeds and read the listing there.
- If you can only get part of the job description, tell me before going further.

### 2. Add the job to my tracker
Open my tracker in a new tab and go to the Jobs tab.
- Search the Jobs tab for the company. If this job is already there, use that card instead of adding a second one.
- Otherwise click "Add a role", fill in company, job title, location, listing link, pay and sector, and click "Save role".
- Open the job's card. Paste the full job description into its job description box. Set Status to "Reviewing". If an IEP fits, choose it under "IEP matched".
- In Notes, write two or three plain sentences on what the job covers, then "Concerns:" and any hard requirement in the posting that my resume does not show.

### 3. Tailor the resume and cover letter
On the same card:
- In "Instructions for this draft", list anything the posting asks for that my resume does not show and say not to claim it, then say what my resume should lead with for this job.
- Set Tailor to "Both" and click "Tailor". Wait until both drafts appear.

### 4. Check the drafts
Read both drafts on the card. If any of these rules is broken, write the fix in the instructions box and click "Tailor" again. That revises the last draft instead of starting over. Repeat until both drafts pass.
- Every fact comes from my resume. No invented employers, titles, dates, numbers, tools or results.
- Nothing I have said must never be claimed, and nothing the posting asks for that my resume does not show.
- The resume and cover letter agree: same numbers, same titles, same scope.
- The posting's job title is not put on me, and its sentences are not copied.
- No claims about the employer that the posting does not state.
- Plain, natural writing. No buzzwords, no em dashes, no dramatic one-line sentences.

### 5. Save the files
Click "Download both (.zip)" on the card. If I asked for Google Drive, create a folder named for the company inside the folder I named, upload both files there, and add a link to each file on the card with "Add a document link".

## Reply to me
Keep it short:
- One line saying the job is in my tracker and where the files are, with the link to the card.
- Anything you changed in step 4, and why.
- Any requirement in the posting I do not meet, stated plainly.
